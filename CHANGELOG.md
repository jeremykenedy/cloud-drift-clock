# Changelog

## [1.0.1] - 2026-10-08

Fixed settings and scene startup when an older installation stored a choice preference with a different value type. Boolean `show_seconds` values are converted to the supported text choice; other invalid values use the documented default.

## [1.0.0] - 2026-10-08

Initial release of Cloud Drift Clock with an animated cloudscape, floating digital time, configurable palettes and motion, host settings provider, and standalone ADB installer.
