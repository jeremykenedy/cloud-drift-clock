# Continuous integration

GitHub Actions runs the Android build and test suite, enforces Java and Python line and branch coverage, checks formatting, validates documentation links and required files, and scans the final APK for Internet permission and tracking components. Actions are pinned to full commit SHAs.

No SonarCloud, CodeFactor, Codacy, Aikido, or Scrutinizer integration is configured. Their badges are not included. CI does not sign release artifacts.
