# Configuration

The D-pad-friendly settings activity is available from the app launcher. It also provides a full-screen animation preview. Changes are saved immediately and apply when the screensaver starts.

| Setting | Options | Default | Behavior |
| --- | --- | --- | --- |
| Sky palette | Daylight, Golden hour, Moonlit, Random | Daylight | Selects natural, warm, or dimmed cloud lighting |
| Cloud density | Light, Balanced, Full, Random | Balanced | Changes cloud framing and foreground cloud depth |
| Cloud motion | Slow, Gentle, Drifting, Random | Gentle | Controls the movement of the cloud layers |
| Clock size | Subtle, Standard, Large, Random | Standard | Changes the local time size |
| Clock movement | Centered, Gentle drift, Wide drift, Random | Gentle drift | Controls clock travel across the screen |
| Time format | 12-hour, 24-hour, Random | 12-hour | Chooses the local time format |
| Show seconds | Off, On, Random | Off | Adds seconds to the clock display |
| Randomize all | On or off | Off | Resolves each random-capable setting when the dream starts |

The clock is the only scene text. See [Settings Provider](SETTINGS_PROVIDER.md) for the app-owned host interface.
