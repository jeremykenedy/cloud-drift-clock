# Cloud Drift Clock v1.0.0

## Breaking changes

None. This is the first release.

## Features

- Adds a full-screen animated cloudscape with a drifting local digital clock.
- Adds daylight, golden-hour, and moonlit palettes, cloud density and speed, clock size and movement, 12-hour and 24-hour formats, optional seconds, and per-setting or full random selection.
- Adds a remote-friendly settings activity, animation preview, and documented settings provider.
- Adds a checksum-verifying standalone ADB installer and Apache-2.0 license.

## Commands

- Install or update: `python3 install.py --serial TV_IP:5555`
- Install a local APK: `python3 install.py --serial TV_IP:5555 --apk build/cloud-drift-clock.apk`
- Remove interactively: `python3 install.py --serial TV_IP:5555 --uninstall`
- Remove non-interactively: `python3 install.py --serial TV_IP:5555 --uninstall --yes --force`

## Upgrade

For this first release, install the signed APK over an existing installation with `adb install -r`. Future releases must use the same signing key to preserve app-local preferences.

## Device status

Android TV emulator settings and animation preview were checked at API 31 and 1920 by 1080. Fire TV, Android TV, and Google TV physical-device validation remains open; see [device verification](../VERIFICATION.md).
