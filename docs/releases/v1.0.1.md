# Cloud Drift Clock 1.0.1

This patch release prevents a stored choice preference with an old value type from crashing the settings screen or screensaver. A Boolean `show_seconds` value is converted to its supported text choice. Other unsupported stored types use the documented setting default.

There are no breaking changes, new commands, or new settings. Existing valid choices remain unchanged.

## Upgrade

Update through Fire TV Toolkit with `firetv-screensavers --install=cloud-drift-clock --yes`, or install the signed APK over the existing version with `adb install -r cloud-drift-clock.apk`. Both keep the existing app data; incompatible choice values are normalized when read.

## Verification

- Host tests passed with 100% line and branch coverage of the tested project logic.
- The signed APK opened its settings and rendered the DreamService on an Android TV API 31 emulator at 1920 by 1080.
- The Fire TV UI preview path started the DreamService and restored the previous screensaver selection and enabled state on exit.
- Physical Fire TV, Android TV, and Google TV behavior, automatic idle activation, native 4K output, and hardware performance remain untested.
